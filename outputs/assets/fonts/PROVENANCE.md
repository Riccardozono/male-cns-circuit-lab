# Local UI fonts

Fonts are embedded locally for the offline Windows app. No runtime request to
Google Fonts is made. Original font binaries are unmodified.

- Tajawal Bold: Copyright 2018 Boutros International.
  [Original font](https://github.com/google/fonts/blob/main/ofl/tajawal/Tajawal-Bold.ttf),
  license in OFL-Tajawal.txt (SIL Open Font License 1.1).
- Sintony Bold:
  [Original font](https://github.com/google/fonts/blob/main/ofl/sintony/Sintony-Bold.ttf),
  license and copyright in OFL-Sintony.txt (SIL Open Font License 1.1).

Retrieved 13 October 2026. The approved UI comp's brand and lap numerals were
measured with Impeccable; catalog fingerprint ranking, without a browser rank,
suggested these faces. Body and native controls retain Segoe UI/system UI.

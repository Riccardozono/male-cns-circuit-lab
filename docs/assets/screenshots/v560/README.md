# Anteprime native — app 5.6.0

Quattro PNG copiati **identici per byte** dalla QA nativa del sorgente 5.6.0,
identificato dal [tag v5.6.0](https://github.com/Riccardozono/male-cns-circuit-lab/tree/v5.6.0).
Gli originali e le anteprime precedenti 5.5.0 sono conservati.

## Origine

- Acquisizione Electron con `desktop/circuit-3d-smoke.cjs`;
  rapporto generato `2026-10-12T17:54:12.635Z`.
- Windows, Ryzen 5 5600G e RTX 4060 verificati localmente. Scena WebGL 2,
  backend neurale WebGPU attivo, adattatore identificato `nvidia lovelace`.
- Profilo di prova separato dai progressi dell'autore; simulazione in pausa,
  quattro piste e 100 agenti. Attività dell'atlante già calcolata, non una
  posa o una dimostrazione di apprendimento.
- QA **104/104**, zero errori di console; quindici catture ispezionate,
  qui sono pubblicati soltanto quattro PNG.
- Ogni file è **1524 × 941 pixel**. Nessun ritaglio, ridimensionamento,
  ritocco o generazione con IA. L'attributo `width` del README influenza
  soltanto la visualizzazione sul sito.
